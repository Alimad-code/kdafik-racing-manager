# Kdafik Racing Manager

Kdafik Racing Manager — одиночный менеджер формульного сезона: соберите команду, управляйте бюджетом и проведите её через чемпионат.

## Локальная разработка

Одна команда запускает PostgreSQL, миграции, FastAPI и Vite dev-server в Docker:

```powershell
docker compose up --build -d
```

Откройте приложение на [http://localhost:5173](http://localhost:5173). Vite
проксирует запросы `/api` и WebSocket-соединения на backend. Документация FastAPI
доступна напрямую на [http://localhost:8000/docs](http://localhost:8000/docs).

Локальный запуск не использует Nginx или TLS: Nginx является только production-edge.
Подробности: [локальный запуск](docs/deployment/local.md). Для публичного размещения
используйте [production-инструкцию](docs/deployment/production.md).

## Игровые правила

- Выберите одну команду и двух разных пилотов; их стоимость и строительство двух болидов списываются из стартового бюджета 130M.
- Сезон включает 12 этапов. Каждый проходит последовательно: практика, квалификация, гонка.
- Настройки болидов влияют на темп и оплачиваются из резерва настроек, а затем из свободного бюджета. Ремонт сначала использует ремонтный резерв.
- Повреждения замедляют болид; сильно повреждённый болид нельзя выпустить в следующую сессию без ремонта.
- Очки получают первые десять пилотов: 25, 18, 15, 12, 10, 8, 6, 4, 2 и 1. После гонки обновляются личный и командный зачёты.
- После двенадцатой гонки сезон завершается.

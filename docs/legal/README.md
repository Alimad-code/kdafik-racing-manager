# Финализация legal set

> **DRAFT / НЕ ФИНАЛЬНО / ТРЕБУЕТ ПРОВЕРКИ РОССИЙСКИМ ЮРИСТОМ**

Этот каталог содержит минимальные черновики для Russia-only аудитории:

- `privacy-policy.md` — политика обработки персональных данных;
- `personal-data-consent.md` — отдельное согласие на обработку персональных данных;
- `user-agreement.md` — отдельное пользовательское соглашение;
- `cookie-storage-notice.md` — уведомление о cookie и локальном хранилище.

## Перед production-публикацией

- подтвердить личность, статус и адрес оператора;
- выбрать и проверить правовые основания обработки;
- утвердить сроки хранения и удаления;
- проверить хостинг, обработчиков и трансграничную передачу;
- утвердить возрастную и договорную модель для контента 6+;
- указать рабочий контакт для обращений;
- присвоить версии, даты и SHA-256 каждому публикуемому тексту;
- заменить [ПУБЛИЧНЫЙ ДОМЕН] и все placeholders;
- получить письменное одобрение публикации в production.

Нужны отдельные явные действия для: ознакомления с политикой, согласия на обработку персональных данных и принятия пользовательского соглашения. Публикация и связанное с ней юридическое/внешнее взаимодействие остаются вне этого чернового набора.

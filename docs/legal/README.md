# Финализация legal set

Этот каталог содержит минимальный набор документов для аудитории в Российской Федерации:

- `privacy-policy.md` — политика обработки персональных данных;
- `personal-data-consent.md` — отдельное согласие на обработку персональных данных;
- `user-agreement.md` — отдельное пользовательское соглашение;
- `cookie-storage-notice.md` — уведомление о cookie и локальном хранилище.

## Текущий статус

В проект внесены: домен `kdafik-racing.ru`, сведения об операторе и контакте, бесплатная некоммерческая модель, состав обрабатываемых данных, цели, сроки для учётных и сессионных данных, модель «контент 6+ / учётная запись 18+» и тексты отдельных согласий. В качестве целевой инфраструктуры зафиксированы VDS и основная база данных Selectel в московском регионе, ежедневные резервные копии в российском Selectel S3 сроком до 30 дней и Почтовый сервис Selectel с адресом отправителя `no-reply@kdafik-racing.ru`.

Документы остаются предзапускными (`isDraft: true` в манифесте), пока эта схема не создана и не проверена на практике. После настройки VDS, базы данных, S3-копий и сервисной почты требуется утвердить финальную дату вступления в силу, снять статус черновика и обновить контрольные суммы.

В интерфейсе уже предусмотрены отдельные явные действия для: ознакомления с политикой, согласия на обработку персональных данных и принятия пользовательского соглашения. Перед запуском необходимо дополнительно реализовать явное подтверждение возраста 18+ при регистрации, чтобы технический поток соответствовал этим документам.

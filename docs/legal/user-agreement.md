Настоящее соглашение регулирует использование сервиса Kdafik Racing Manager по адресу `kdafik-racing.ru`.

## 1. Сервис и стороны

Сервис предоставляет Джафаров Алимад, физическое лицо, адрес для корреспонденции: г. Москва, ул. 800-летия Москвы, дом 28, корпус 1 (далее — «Оператор»).

Kdafik Racing Manager — бесплатный однопользовательский сервис управления виртуальным гоночным сезоном. Сервис не предусматривает платежи, рекламу, ставки, азартные игры, призы, финансовые операции или иную монетизацию.

Контент Сервиса имеет возрастную маркировку **6+**. Создать учётную запись и принять настоящее соглашение может только пользователь, достигший 18 лет.

## 2. Учётная запись

Для использования функций Сервиса требуется учётная запись. Пользователь указывает действующий адрес электронной почты, отображаемое имя и пароль, подтверждает адрес электронной почты кодом из письма и принимает актуальные юридические документы отдельными чекбоксами.

Пользователь обязан сохранять конфиденциальность пароля, не передавать доступ к учётной записи другим лицам и незамедлительно сообщать Оператору о предполагаемом несанкционированном доступе по адресу kdafikracing@yandex.ru.

Пользователь может удалить учётную запись через доступную функциональность Сервиса. До удаления пользователь может экспортировать связанные с учётной записью данные, если эта возможность доступна в интерфейсе.

## 3. Допустимое использование

Пользователь обязуется использовать Сервис законно и добросовестно. Запрещается:

- обходить технические ограничения, меры безопасности или ограничения частоты запросов;
- получать доступ к чужим учётным записям, данным или сессиям;
- использовать автоматизированные средства, создающие чрезмерную нагрузку на Сервис;
- распространять вредоносное программное обеспечение, спам или материалы, нарушающие права третьих лиц;
- использовать Сервис для ставок, азартных игр, платежей или извлечения дохода.

При нарушении этих условий Оператор вправе ограничить доступ к Сервису, удалить учётную запись или принять иные меры, необходимые для защиты Сервиса и его пользователей.

## Используемые технологии хранения

Сервис использует только функциональные механизмы, необходимые для аутентификации и работы интерфейса:

- refresh-cookie `kdafik_refresh_token` с атрибутами `HttpOnly`, `Secure` и `SameSite=Lax` — для поддержания аутентифицированной сессии; JavaScript страницы не имеет доступа к значению cookie;
- access token — хранится только в памяти приложения и не записывается в cookie или постоянное хранилище браузера;
- ключи `localStorage` с префиксом `kdafik:*` — функциональные, неидентифицирующие настройки интерфейса.

Сервис не заявляет рекламные, аналитические, маркетинговые или иные необязательные отслеживающие cookie. Поэтому уведомление не предусматривает баннер общего согласия.

## Цели, сроки и управление

Цели использования — поддержание сессии, безопасность доступа и сохранение функциональных настроек интерфейса. Конкретные сроки жизни refresh-cookie, access token и ключей `kdafik:*` должны быть утверждены: [СРОКИ ХРАНЕНИЯ].

Пользователь может удалить локальные данные средствами браузера. Последствия удаления и точный порядок управления настройками должны быть описаны после проверки: [ПОРЯДОК УПРАВЛЕНИЯ]. Ограничение обязательных механизмов может повлиять на вход в учётную запись или работу интерфейса.

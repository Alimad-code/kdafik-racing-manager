# Уведомление о cookie и локальном хранилище

Это уведомление относится к сервису Kdafik Racing Manager по адресу `kdafik-racing.ru`.

## Используемые технологии хранения

Сервис использует только функциональные механизмы, необходимые для аутентификации, безопасности и работы интерфейса:

- refresh-cookie `kdafik_refresh_token` с атрибутами `HttpOnly`, `Secure` и `SameSite=Lax` — для поддержания аутентифицированной сессии; JavaScript страницы не имеет доступа к значению cookie;
- access token — хранится только в памяти приложения и не записывается в cookie или постоянное хранилище браузера;
- ключ `localStorage` `kdafik:broadcast-transitions:v1` — для сохранения настройки интерфейса, не содержащей персональных данных.

Срок жизни refresh-cookie составляет не более 30 дней. Данные в `localStorage` остаются в браузере, пока пользователь не удалит их самостоятельно или пока не будет изменена настройка интерфейса.

Сервис не использует рекламные, аналитические, маркетинговые или иные необязательные отслеживающие cookie. Поэтому отдельный баннер согласия на такие cookie не показывается.

Пользователь может удалить cookie и данные локального хранилища в настройках браузера. После удаления функциональных данных может потребоваться повторный вход в учётную запись; настройка интерфейса будет сброшена.

Сведения об Операторе, обработке персональных данных и контакте для обращений приведены в Политике обработки персональных данных.
